# GPU crash investigation — November 15, 2026

**Symptom:** An accelerated long dictation coincided with NVIDIA TDR events and a native Python abort, losing audio held inside that worker.

**Root cause:** The dump's resolved exception stack shows a C++ cleanup exception in CTranslate2's asynchronous CUDA allocator, through a StorageView destructor, followed by CRT terminate/abort. The NVIDIA reset occurred first. The driver timeout's underlying trigger is not established.

Windows denied access to the privileged kernel TDR reports; application-dump analysis was available. No privileged access or security-policy changes were performed.

**Fix:** Isolate unchanged CUDA decoding in a hidden owned interpreter. Verify and job-bind its actual PID before initialization. Use exact float32 framed transport, bounded queues, full RPC deadlines and fail-closed runtime latching. Retain capture/text and refuse incomplete insertion. Files: `lightningflow/asr_process.py`, `lightningflow/app.py`, `lightningflow/desktop/worker.py`.

**Evidence:** Regression tests failed before fault latching and passed afterward. Actual CUDA child termination in both modifier modes retained audio/text and the control worker. The suspended-child test verified a deadline during pipe writing. Direct/isolated synthetic transcripts matched. The final long run completed 30 minutes of synthetic audio in each mode with identical reference-matching hashes and zero observed NVIDIA TDR events. The 200-cycle run also passed. See public JSON and FIXES_0.6.1.md for timings and scope.

**Regression tests:** `tests/test_gpu_faults.py`, `tests/test_asr_process.py`, `tests/gpu_isolation_integration.py`, `tests/long_recording_integration.py`.

**Related:** The alternative CUB allocator also failed an isolated invalid-context probe, so switching allocators was rejected. Assigning only the Windows Store launcher's job did not contain its real interpreter; the pre-initialization PID handshake fixes that ownership gap. No driver upgrade, global GPU reset, TDR-registry change or accuracy/precision reduction was used.

**Status:** DONE_WITH_CONCERNS — native failure containment is verified; the external driver-reset trigger and universal long-session stability are not proven.
